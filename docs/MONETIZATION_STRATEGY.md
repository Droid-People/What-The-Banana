## 단기 전략: 기존 광고 최적화 (0~1개월)

### 1. 전면 광고 자연스러운 삽입 포인트

현재 전면광고가 데모 화면에만 있고 실제 사용 흐름에 없음. 아래 시점에 삽입 권장:

| 삽입 시점 | 화면 | 이유 |
|-----------|------|------|
| 룰렛 결과 표시 직전 | `roulette_result_view.dart` | 스핀 완료 → 광고 → 결과 공개. 기대감 활용 |
| 사다리 결과 표시 직전 | `ghost_leg_result_view.dart` | 애니메이션 완료 → 광고 → 결과. 자연스러운 전환 |
| 픽셀아트 저장/공유 시 | `pixel_art_screen.dart` | 작품 완성 후 저장 전. 성취감 순간 활용 |
| QR 코드 저장 시 | `qr_maker_screen.dart` | 갤러리 저장 전 리워드 광고 |

**예상 효과:** 홈 배너만 있는 현재 대비 광고 수익 3~5배 증가 가능

### 2. 네이티브 광고 홈 삽입

홈 스크롤 중간에 네이티브 광고 카드를 1~2개 삽입. 바나나 테마에 어울리는 자연스러운 배치.

### 3. 앱 오픈 광고 활성화

앱 시작 시 또는 백그라운드 복귀 시 앱 오픈 광고 표시. 이미 구현되어 있으므로 `main.dart`에서 연결만 하면 됨.

## 중기 전략: 프리미엄 모델 도입 (1~3개월)

### 4. 광고 제거 구독 (Ad-Free Subscription)

| 항목 | 설계 |
|------|------|
| 가격 | 월 $0.99 또는 연 $4.99 |
| 패키지 | `in_app_purchase` (Flutter 공식) |
| 혜택 | 모든 광고 제거 |
| 구현 난이도 | 중간 (StoreKit/Play Billing 연동) |

**가장 안정적인 수익원.** 유틸리티 앱 특성상 반복 사용 유저가 광고 피로감을 느끼면 자연스럽게 전환.

### 5. 프리미엄 픽셀아트 기능

| 무료 | 프리미엄 |
|------|----------|
| 16x16 캔버스 | 32x32, 64x64, 128x128 캔버스 |
| 기본 색상 팔레트 18색 | 확장 팔레트 72색+ |
| - | 레이어 기능 |
| - | 커스텀 팔레트 저장 |

**일회성 구매 $1.99 또는 구독 포함**

### 6. 프리미엄 테마 팩

| 무료 | 프리미엄 |
|------|----------|
| 기본 바나나 테마 | 열대과일 테마, 우주 테마 등 |
| - | 룰렛/사다리 커스텀 효과음 |
| - | 다크 모드 (기능 제안서 참고) |

## 장기 전략: 커뮤니티 & 생태계 (3~6개월)

### 7. 바나나 코인 경제

```
광고 시청 → 바나나 코인 획득 → 프리미엄 기능 해금
                              → 픽셀아트 갤러리 아이템 구매
                              → 커스텀 테마 해금
```

- 리워드 광고 시청 = 10 코인
- 프리미엄 기능 해금 = 100~500 코인
- 코인 직접 구매도 가능 ($0.99 = 200 코인)

**장점:** 무과금 유저도 광고를 통해 프리미엄 기능 이용 가능 → 리텐션 증가 + 광고 수익 증가

### 8. 픽셀아트 마켓플레이스

- 유저 작품 공유 (무료)
- 인기 작품 스티커/배경화면으로 판매
- 작가에게 수익 공유 (70:30)
- **장점:** UGC(User Generated Content)로 콘텐츠 자동 생산

### 9. 소그룹/단체 전용 플랜

| 항목 | 설계 |
|------|------|
| 타겟 | 교회, 동아리, 소규모 단체 |
| 가격 | 월 $4.99 / 단체 |
| 기능 | 실시간 투표, 그룹 카운터, 팀 나누기, 커스텀 브랜딩 |
| 근거 | 이미 평화교회 이스터에그가 있으므로 실수요 존재 |

## 핵심 원칙

1. **무과금 유저 경험 해치지 않기** - 광고는 자연스러운 전환점에만. 강제 광고 최소화
2. **프리미엄은 "더 좋은 경험"이지 "필수 기능"이 아님** - 무료로도 모든 기본 기능 사용 가능
3. **커뮤니티가 수익을 만든다** - UGC, 공유, 그룹 기능이 바이럴과 리텐션을 동시에 해결

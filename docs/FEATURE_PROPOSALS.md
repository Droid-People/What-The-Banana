# What The Banana - 기능 제안서

> 작성일: 2026-04-12

## 현재 앱 기능 현황

| 기능 | 상태 | 비고 |
|------|------|------|
| 듀얼 카운터 | 활성 | 세로/가로 모드, 이스터에그(교회 모드) |

| 사다리 타기 | 활성 | 2~7명 참여자 |

| 기부 | 미완성 | "Not ready" 표시 |

## 추가 기능 제안

### Tier 1: 낮은 난이도 / 높은 시너지

#### 1. 주사위 굴리기 (Dice Roller)
- **설명:** 1~6개 주사위를 동시에 굴리는 기능. 3D 애니메이션 또는 바나나 테마 주사위
- **시너지:** 룰렛, 사다리와 같은 "랜덤 도구" 카테고리로 묶임
- **구현 예상:** CustomPainter + Animation, 상태 관리 간단
- **타겟:** 보드게임 유저, TRPG 유저

#### 2. 타이머 / 스톱워치 (Timer & Stopwatch)
- **설명:** 바나나가 익어가는 애니메이션과 함께 동작하는 타이머
- **시너지:** 카운터와 함께 "측정 도구" 카테고리
- **구현 예상:** Timer 클래스 + 커스텀 UI
- **타겟:** 요리, 운동, 보드게임 시간 제한

#### 3. 팀 나누기 (Team Divider)
- **설명:** 이름 입력 → N개 팀으로 랜덤 배정
- **시너지:** 사다리타기와 비슷하지만 "그룹 배정" 특화 UX
- **구현 예상:** 기존 InputTextView 재활용 가능
- **타겟:** 체육시간, 모임, 회식 자리

#### 4. 동전 던지기 (Coin Flip)
- **설명:** 앞/뒤 선택. 바나나 동전 테마 + 플립 애니메이션
- **시너지:** 랜덤 도구 카테고리의 가장 간단한 형태
- **구현 예상:** AnimationController + Transform

### Tier 2: 중간 난이도 / 커뮤니티 확장

#### 5. 실시간 투표/설문 (Live Poll)
- **설명:** Firestore 기반 실시간 투표. 방 코드로 참여
- **시너지:** 피드백 기능의 Firestore 인프라 활용
- **구현 예상:** Firestore 실시간 리스너 + QR 코드 공유
- **타겟:** 모임, 수업, 발표에서 즉석 투표

#### 6. 픽셀아트 갤러리 (Community Gallery)
- **설명:** 픽셀 작품 공유, 좋아요, 다운로드
- **시너지:** 기존 픽셀아트 기능 + Firestore
- **구현 예상:** Firestore Storage + 이미지 업로드/다운로드
- **타겟:** 창작 커뮤니티, SNS 공유 유도

#### 7. 홈 위젯 (Home Widget)
- **설명:** iOS/Android 홈 화면 위젯 (만보기 걸음수, 카운터)
- **시너지:** 앱 진입 없이 기능 사용 → 리텐션 향상
- **구현 예상:** `home_widget` 패키지 활용
- **타겟:** 일상적 사용 유도

#### 8. 다크 모드 (Dark Mode)
- **설명:** 현재 라이트 테마만 지원. 시스템 설정 연동 다크 모드
- **시너지:** 모든 화면에 영향. 사용자 경험 개선
- **구현 예상:** ThemeData.dark() 기반 + ColorName 확장

### Tier 3: 높은 난이도 / 장기 비전

#### 9. 미니게임 (Banana Games)
- **설명:** 바나나 잡기, 바나나 퍼즐 등 간단한 캐주얼 게임
- **시너지:** 앱 체류 시간 증가, 광고 노출 기회 확대
- **타겟:** 심심할 때 가볍게 즐기는 유저

#### 10. 소그룹/모임 전용 기능 (Group Mode)
- **설명:** QR 코드로 방 생성 → 룰렛/사다리/투표를 그룹이 함께 사용
- **시너지:** 이스터에그(교회 모드)를 정식 기능화
- **타겟:** 교회 청년부, 동아리, 소그룹 모임

## 우선 추천 구현 순서

```
Phase 1 (1~2주): 주사위 + 동전 던지기 + 팀 나누기
  → 랜덤 도구 카테고리 완성, 앱 밸류 즉시 증가

Phase 2 (2~4주): 다크 모드 + 타이머
  → 사용성 개선, 리텐션 향상

Phase 3 (1~2개월): 실시간 투표 + 픽셀아트 갤러리
  → 커뮤니티 기능으로 사용자 확보
```
